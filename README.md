# 🔥 Roast Me — Click & Get Roasted 😈

> *“If you cry, that’s part of the fun.”* 😌🔥

**Roast Me** is a fun, interactive frontend web app where users can press a button and receive a brutally funny roast.  
Built purely for entertainment, learning, and UI experimentation — **no backend drama, only frontend magic** ✨

🌐 **Live Demo:**  
👉 https://roastmee.onrender.com  

---

## 😈 What Is Roast Me?

Roast Me is a **frontend-only React app** created just for fun 🤪  
The idea is simple:

- You click a button
- The app roasts you (mercilessly 😈)
- You laugh, cry, or share it with friends 😂

No signups. No database. No feelings spared.

---

## 🚀 Features

- 🔥 One-click **instant roast**
- 🎯 Random & fun roast messages
- 🎨 Clean, dark-themed modern UI
- 💫 Smooth animations & transitions
- 🔁 Reset button to start fresh
- 📱 Fully responsive (mobile + desktop)
- ⚡ Fast performance (Vite + React)
